# Campus Lost & Found System

## 1. Problem Statement

In a college campus, students and staff may lose personal belongings such as ID cards, books, wallets, mobile phones, keys, and other items. Currently, information about lost and found items may be shared through informal communication, making it difficult to find the correct owner.

The **Campus Lost & Found System** provides a simple command-line-based solution for recording lost and found items. Users can add details about items, view available records, and search for items based on their information. This helps make the process of reporting and finding lost belongings more organized and convenient.

## 2. Scope of the Project

The project is designed for use within a college or university campus. It focuses on maintaining basic records of lost and found items.

The system can be used to:

* Add details of lost or found items.
* Store information such as item name, description, location, and contact details.
* Display the list of reported items.
* Search for a particular lost or found item.
* Help users identify possible matches between lost and found belongings.

The current version is a simple **Java command-line application**. In the future, it can be extended with a database, graphical user interface, login system, notifications, and online access.

## 3. Target Users

The main target users of the system are:

* **Students** – to report lost belongings or found items.
* **Faculty members** – to report or search for lost and found items.
* **College staff** – to maintain and manage lost-and-found records.
* **Campus administration** – to organize and monitor lost-and-found activities.

## 4. High-Level Features

The Campus Lost & Found System provides the following features:

1. **Add Lost Item** – Allows users to enter details of an item they have lost.
2. **Add Found Item** – Allows users to record an item they have found on campus.
3. **View Items** – Displays the available lost and found item records.
4. **Search Items** – Helps users search for items using relevant information.
5. **Item Details** – Stores information such as item name, description, location, and contact details.
6. **Simple Menu-Based Interface** – Provides an easy-to-use command-line menu.
7. **Java-Based Implementation** – Developed using basic Java programming concepts such as classes, objects, methods, collections, and user input.
8. **Future Extensibility** – The system can later be connected to a database or converted into a web/mobile application.

## Conclusion

The Campus Lost & Found System provides a simple and organized way to manage lost and found belongings within a college campus. It reduces dependence on informal communication and provides a structured method for recording, viewing, and searching item information.
