# Campus Lost & Found System

## About the Project

Campus Lost & Found System is a simple Java command-line application designed to help students report and search for lost and found items on a college campus.

The project provides a basic way to record item information such as the item name, type, and location.

## Features

* Report a lost item
* Report a found item
* View all reported items
* Search for an item
* Automatic item ID generation
* Basic exception handling for invalid menu input

## Technologies Used

* Java
* ArrayList
* Scanner
* Object-Oriented Programming
* Command Line Interface (CLI)

## How to Run

### Step 1: Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/Campus-Lost-and-Found.git
```

### Step 2: Open the Project Folder

```bash
cd Campus-Lost-and-Found
```

### Step 3: Compile the Program

```bash
javac LostAndFound.java
```

### Step 4: Run the Program

```bash
java LostAndFound
```

## Menu

================================
     CAMPUS LOST & FOUND
================================
1. Report Lost Item
2. Report Found Item
3. View All Items
4. Search Item
5. Exit
```

## Example

A student can report:

```text
Item Name: Black Wallet
Location: Library
Type: LOST
```

The system generates an item ID and stores the information.

The user can later search for the item using its name.
